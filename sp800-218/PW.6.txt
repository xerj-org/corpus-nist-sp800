id: PW.6
title: Configure the Compilation, Interpreter, and Build Processes to Improve Executable Security
family: Produce Well-Secured Software (PW)
class: practice
family-overview: Organizations should produce well-secured software with minimal security vulnerabilities in its releases.

Statement:
Decrease the number of security vulnerabilities in the software and reduce costs by eliminating vulnerabilities before testing occurs.

========================================================================
Child control PW.6.1 - PW.6.1

Statement:
Use compiler, interpreter, and build tools that offer features to improve executable security.

Example:
Use up-to-date versions of compiler, interpreter, and build tools.

Example:
Follow change management processes when deploying or updating compiler, interpreter, and build tools, and audit all unexpected changes to tools.

Example:
Regularly validate the authenticity and integrity of compiler, interpreter, and build tools. See PO.3.

Child control PW.6.2 - PW.6.2

Statement:
Determine which compiler, interpreter, and build tool features should be used and how each should be configured, then implement and use the approved configurations.

Example:
Enable compiler features that produce warnings for poorly secured code during the compilation process.

Example:
Implement the “clean build” concept, where all compiler warnings are treated as errors and eliminated except those determined to be false positives or irrelevant.

Example:
Perform all builds in a dedicated, highly controlled build environment.

Example:
Enable compiler features that randomize or obfuscate execution characteristics, such as memory location usage, that would otherwise be predictable and thus potentially exploitable.

Example:
Test to ensure that the features are working as expected and are not inadvertently causing any operational issues or other problems.

Example:
Continuously verify that the approved configurations are being used.

Example:
Make the approved tool configurations available as configuration-as-code so developers can readily use them.
