id: PO.4
title: Define and Use Criteria for Software Security Checks
family: Prepare the Organization (PO)
class: practice
family-overview: Organizations should ensure that their people, processes, and technology are prepared to perform secure software development at the organization level. Many organizations will find some PO practices to also be applicable to subsets of their secure software development, like individual development groups or projects.

Statement:
Help ensure that the software resulting from the SDLC meets the organization’s expectations by defining and using criteria for checking the software’s security during development.

========================================================================
Child control PO.4.1 - PO.4.1

Statement:
Define criteria for software security checks and track throughout the SDLC.

Example:
Ensure that the criteria adequately indicate how effectively security risk is being managed.

Example:
Define key performance indicators (KPIs), key risk indicators (KRIs), vulnerability severity scores, and other measures for software security.

Example:
Add software security criteria to existing checks (e.g., the Definition of Done in agile SDLC methodologies).

Example:
Review the artifacts generated as part of the software development workflow system to determine if they meet the criteria.

Example:
Record security check approvals, rejections, and exception requests as part of the workflow and tracking system.

Example:
Analyze collected data in the context of the security successes and failures of each development project, and use the results to improve the SDLC.

Child control PO.4.2 - PO.4.2

Statement:
Implement processes, mechanisms, etc. to gather and safeguard the necessary information in support of the criteria.

Example:
Use the toolchain to automatically gather information that informs security decision-making.

Example:
Deploy additional tools if needed to support the generation and collection of information supporting the criteria.

Example:
Automate decision-making processes utilizing the criteria, and periodically review these processes.

Example:
Only allow authorized personnel to access the gathered information, and prevent any alteration or deletion of the information.
